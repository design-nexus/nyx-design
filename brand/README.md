# Nyx mark

The eclipse: a dark moon with a glowing rim, from the Nyx Dark wallpapers.

| File | Use |
| --- | --- |
| `nyx-mark.svg` | The mark. The rim is `currentColor`, so it takes the active theme's accent (set `color` on it; the file defaults to Nyx Dark's `#5b9cff`). |
| `nyx-mark-silver.svg` | A silver rim, for monochrome places: the boot splash, the login screen over a wallpaper. |
| `nyx-mark-small.svg` | 16 to 48 px: no glow or stars, a thicker rim. |
| `nyx-lockup.svg` | The mark with the wordmark, NYX in Inter Light, widely spaced. |

![The lockup](preview.png)

Keep the rim on the right. Solid surfaces only behind it, no glass. Below 48 px, use
the small version.
