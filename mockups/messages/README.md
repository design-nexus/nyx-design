# Nyx Messages: layout options

SMS/RCS desktop client (Google Messages pairing). This gallery is **layout directions only** —
pick A–D before pairing, share and notification screens.

| | Idea |
| --- | --- |
| **A · Split inbox** | Two panes: list \| chat. Segment filters on the list. No places sidebar. |
| **B · People first** | Favorites strip + large recent people; chat with an avatar rail. |
| **C · Focus** | Conversation fills the window; jump via a header chat picker. |
| **D · Stack** | One column for tiling: list page → chat page with Back. |

Open `index.html`, or `screens.html?screen=a-chat&theme=dark`. `./render.sh` writes `shots/`.
