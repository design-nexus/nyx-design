Nyx polish mockups

Proposals for a cleaner, more polished, macOS-like finish that keeps Nyx Design 2.0: one surface, Inter, accent only for state, every colour a token. Findings and the full proposal list are in AUDIT.md. “Before” is rebuilt from today's CSS values; each page is live HTML with its own switcher.

  • Type: seven sizes in em (11 / 12 / 13 / 15 / 17 / 22 / 26), Inter Display from 20 px, weights 400–600, no wide tracking.
  • Labels: sentence-case sidebar groups; section colour moves to icon tiles.
  • Space: 4 px grid, pages 20 / 24 / 32, a shared 720 px cap for option pages and 680 px for reading.
  • Rows: 44 px option rows with inset dividers; 32 px list rows; quiet column headers.
  • Chrome: app name in text colour, 28 px icon buttons and fields, no edge bar on the selected item, a focus ring.
  • Media: radius-7 art with a soft shadow, no glow; 20 / 24 grid gaps; flat player bar.
  • Variant B: an inset, tinted sidebar running the full height with the app's name at its top.
