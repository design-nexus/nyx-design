Nyx TV · Appearance redesign

Four ways to rebuild Settings → Appearance. Every direction keeps Cancel / Apply, all nine themes, and a preview that stays visible while you move. The bottom-left key hints are the D-pad contract for that layout — pick the one whose navigation feels obvious.

A · Sticky strip + gridCompact preview bar above a 3×3 theme grid. Left only returns to the sidebar from the left column.
B · Home restyles behindLike the original TV mockup: the dimmed home behind the panel is the preview. Larger theme cards.
C · CarouselOne big theme at a time. ← → change themes and never leave the page; Back is the only exit to the sidebar.
D · List + side previewSingle-column theme list (↑↓ only). Sticky live preview on the right. Simplest 1D focus.
