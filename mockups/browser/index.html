Nyx Browser

Browser's chrome in Nyx Design 2.0, for the Zen source fork: one frame surface for the top bar, sidebar and foot, with the page as an inset sheet; vertical tabs by default and horizontal tabs as a full alternative; the sidebar's four modes; the minimal top bar (back, forward, reload, the address field, the action area, Settings and the menu) with More tools when the window is narrow. Security and permission indicators stay as Firefox draws them. Every shot comes in Catppuccin Mocha (NyxOS's default), Nyx Dark and Nyx Light.
