Nyx icon sets

Icon sets to sit beside Umbra, each covering folders, file types, code, devices and status, plus a matching style for app icons. Umbra Tile and today's app icons come first in every group, for comparison. These are the five kept: G and K are Umbra Tile with one thing changed (the same glyphs, marks and stroke widths); C, D and E are the earlier directions. Each group shows one view across all the sets, so arrowing through a group compares them side by side.

Every set is drawn by code in sets/, which takes the same inputs nyx icons already gives Umbra and the app icons: the theme palette, Umbra's catalog of icon names and marks, and the app glyphs. The check covers every catalog icon at 16, 22, 24, 32 and 48 px and scalable, plus all 40 app glyphs and a logo, in Nyx Dark, Nyx Light and all 23 Omarchy themes. Every icon came out as valid SVG, librsvg (what GTK uses) drew every icon tried, and brand and language marks are left exactly as Umbra draws them.
