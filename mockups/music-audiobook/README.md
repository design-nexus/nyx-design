# Music — multi-media revamp mockups

Same Design 2.0 style, rearranged so Music is a listening app for **all** its media:
local music, Audiobookshelf, podcasts, and radio.

## What’s different

- **Sidebar:** Home, Now playing, then Listen peers (Music · Audiobooks · Podcasts · Radio).
  Songs / Albums / Artists / Genres / Folders / Recent live as chips on the Music page,
  not as six music-only sidebar rows.
- **Player bar:** Same layout as Music: cover + title, one transport row over seek, then the
  right icon cluster and volume. Audiobook mode only swaps the controls (skip / chapter /
  play / chapter / skip; bookmark and book details instead of lyrics and Up next).
- **Now playing:** One page. Audiobook mode uses the right column for chapters and
  bookmarks; music mode keeps spectrum and Up next. No separate spoken page.
- **Audiobooks library:** Directions A (suggested), B, C, plus connection and detail states.
